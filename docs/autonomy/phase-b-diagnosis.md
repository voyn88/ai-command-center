# Phase B diagnosis

1. **Главный вывод по задачам: массовое закрытие PR 2026-10-29 не уменьшило planner fence, потому что задача с закрытым PR навсегда остаётся `READY_TO_REVIEW`.** По `ready_pr_evidence.tsv` и `cache_prs.json` сейчас `106` distinct задач `READY_TO_REVIEW`; bucket приоритета по задаче такой: `MERGED 20`, `CLOSED_ONLY 6`, `OPEN(DIRTY 35, BEHIND-stale 32, BEHIND-checks 7, UNSTABLE 3, DRAFT 2, CLEAN 1)` (`.venv/bin/python .ai-team/tasks/VOYN-PHASE-B/b2_task_buckets.py`). Списки task_id для владельца сохранены в `.ai-team/tasks/VOYN-PHASE-B/ready_tasks_merged.txt` и `.ai-team/tasks/VOYN-PHASE-B/ready_tasks_closed_only.txt`. Пока reconcile не переводит `CLOSED_ONLY` в terminal state, даже полностью закрытый без merge PR не вычитает задачу из fence (`command_center/orchestrator/review_merge.py:4476-4516`).
2. **Код подтверждает точную дыру `closed unmerged`: merge tick special-case-ит merged anomaly, но не закрытый без merge PR.** В `merge_once` после `window_state/window_merged` вызывается `_merged_target_sha`; дальше есть явная ветка только для `merged_without_acceptance_evidence`, а при `pr_closed_unmerged` до этого фикса шёл общий путь `merge_sha is None -> _pr_is_mergeable(...)`, где closed PR оставался skip без перехода статуса (`command_center/orchestrator/review_merge.py:4476-4518`). Это и держит такие задачи в backlog fence. PR-evidence из B2 показывает, что класс не пустой: по evidence-PR было `33` `CLOSED_UNMERGED`, а по task-level bucket осталось минимум `6` `CLOSED_ONLY` задач.
3. **Минимальный B3 фикс:** обрабатывать `merge_reason == "pr_closed_unmerged"` прямо в `merge_once` как terminal cleanup существующего reconcile: перевести родительскую задачу `READY_TO_REVIEW -> REJECTED` через `backlog_transition`, не создавать remediation child и оставить `merged_without_acceptance_evidence` без изменений (`command_center/orchestrator/review_merge.py:4482-4513`). Это соответствует B2-решению из `.ai-team/tasks/VOYN-PHASE-B/b2-decision.md`.
4. **Вторичная причина backlog никуда не делась: основная масса fence — open-задачи, а не closed-only хвост.** Из `106` задач `80` имеют хотя бы один open PR, причём худшие состояния: `DIRTY 35`, `BEHIND-stale 32`, `BEHIND-checks 7`, `UNSTABLE 3`, `DRAFT 2`, `CLEAN 1` (`b2_task_buckets.py`; блокировки определяются в `review_merge.py:4966-4998`). Даже полный cleanup `CLOSED_ONLY` не опустит fence ниже 20.
5. **MERGED без acceptance трогать нельзя — это отдельный инцидент владельца, не часть B3.** По task-level bucket сейчас `20` задач уже имеют merged PR, но ещё висят в `READY_TO_REVIEW`; их список сохранён для владельца в `ready_tasks_merged.txt`. Код уже считает этот случай anomalous и только пропускает задачу с причиной `merged_without_acceptance_evidence` (`command_center/orchestrator/review_merge.py:4514-4516` после фикса, прежняя логика сохранена), поэтому B3 лишь чистит closed-unmerged хвост, не меняя этот policy.
